# Quantitative Pairs Trading Strategy

## Overview
A pairs trading strategy on SGX-listed stocks using cointegration, backtesting, and machine learning.

## Key Findings
1. Best cointegrated pairs: **SingTel(Z74.SI) vs CapitaLand Integrated Commercial Trust (C38U.SI)**, p = 0.000229
2. Strategy P&L  after costs: **+0.2244** over 1,305 days.
3. Sharpe Ratio: **0.12**
4. Sortino Ratio: **0.048**
5. Random Forest accuracy: **53.5%** (did not improve strategy)

## Tools Used
1. Python(Pandas, NumPy, Statsmodels, Scikit-learn, Matplotlib)
2. yfinance
